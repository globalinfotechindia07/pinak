# Simple Spring Boot Auth Service

A simple learning project implementing **Authentication and Authorization REST APIs** using Spring Boot.

## Tech Stack

* Java
* Spring Boot
* Spring MVC
* Spring Security
* JWT
* Maven
* H2 Database
* Swagger / OpenAPI

## Getting Started

### 1. Check Java Version

```bash
java -version
```

### 2. Check Maven Version

```bash
mvn -version
```

### 3. Run the Application

From the project root directory:

```bash
mvn spring-boot:run
```

The application will start on:

```text
http://localhost:8080
```

## API Documentation

### Swagger UI

Interactive API documentation and testing:

```text
http://localhost:8080/swagger-ui/index.html
```

### OpenAPI Specification

OpenAPI 3 JSON specification:

```text
http://localhost:8080/v3/api-docs
```

## H2 Database

H2 is used as the in-memory database for development and learning.

H2 Console:

```text
http://localhost:8080/h2-console
```

JDBC URL:

```text
jdbc:h2:mem:authdb
```

## Project Purpose

This project is built to understand:

* Spring MVC
* REST API development
* Authentication
* Authorization
* Spring Security
* JWT
* Role-based access control
* Database persistence
* API documentation using Swagger/OpenAPI
