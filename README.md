# Simple Spring Boot Auth Service

This repository is a learning project that implements a simple Authentication and Authorization REST API using Spring Boot.


Swagger UI (Interactive API Tester): http://localhost:8080/swagger-ui/index.html
OpenAPI 3 JSON Specification: http://localhost:8080/v3/api-docs
H2 Console: http://localhost:8080/h2-console (JDBC URL: jdbc:h2:mem:authdb)
